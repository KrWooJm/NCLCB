## 로또 6/45 데이터 분석기 (`docs/`)

동행복권 전 회차 당첨 데이터를 매주 자동 수집해 통계 분석하고, 예산에 맞춘 구매 조합을
생성하는 정적 웹사이트입니다. 과거 데이터로 당첨 확률을 높일 수 없다는 사실을 분명히 밝히고,
대신 실제로 통제 가능한 것(당첨 시 분할 인원, 포트폴리오 분산)만 최적화합니다.
모든 전략은 과거 전 회차 백테스트로 검증되어 결과가 그대로 공개됩니다.

자세한 내용은 [`docs/README.md`](docs/README.md) 를 참고하세요.
